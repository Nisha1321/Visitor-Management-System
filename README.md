# FaceSense: A Visitor Recognition System

## 🌐 1.1 OVERVIEW

This summer internship project was developed at **Stat Modeller – Robust Kit of Solutions**, a Vadodara-based consultancy specializing in artificial intelligence and machine learning. Known for its innovation in AI-driven analytics and computer vision, Stat Modeller provided the perfect ecosystem for hands-on experience in deep learning and real-time data applications.

The goal of this project was to contribute to a meaningful, impactful solution—**FaceSense**, an intelligent visitor recognition system that detects and analyzes human attributes such as **age, gender, emotion, group dynamics, and individual count** using live CCTV streams.

---

## 🧠 1.2 SUMMARY OF WORK

The core deliverables of the internship revolved around the development of an end-to-end facial recognition system:

- 🧼 **Data Collection & Preprocessing**: Ensuring model-ready input.
- 🧠 **Model Training & Optimization**: Using deep learning for precise face attribute analysis.
- 🗄️ **Database Development**: Efficient storage with MongoDB Atlas.
- 🌐 **Interactive Dashboard**: Built using ReactJS for registration, login, and data visualization.

This project has real-world relevance across **retail, hospitality, and public safety**, offering intelligent insights and operational efficiency.
